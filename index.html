Connect the board

The board reads and writes the private repo Silicon-Melter/agent-board with a GitHub token that stays in this browser.

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → agent-board.
  3. Permissions → Repository permissions → Contents: Read and write. Nothing else.

Saved in this browser's storage for this site only. Use "Forget token" on a shared computer.
