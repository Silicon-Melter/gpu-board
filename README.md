# gpu-board

The GPU board page, published with GitHub Pages at https://silicon-melter.github.io/gpu-board/.

This repo holds only the page. The data lives in the private repo `Silicon-Melter/agent-board`. The page reads and writes it with a fine-grained token that you paste once and that stays in your browser. Edit the pages in `agent-board/web/` and copy the page files here: `index.html` (board), `office.html` (Agent office), `board-core.js` and `board.css` (shared by both), `office-model.js` and `office-flow.js` (the office's views).
