# gpu-board

The GPU board page, published with GitHub Pages at https://silicon-melter.github.io/gpu-board/.

This repo holds only the page. The data lives in the private repo `Silicon-Melter/agent-board`. The page reads and writes it with a fine-grained token that you paste once and that stays in your browser. Edit the page in `agent-board/web/index.html` and copy it here.
